
# 🌱 Feira Circular — Demonstração Front-end

Demonstração da interface inicial do projeto acadêmico **Feira Circular**, desenvolvido com o objetivo de propor soluções tecnológicas para reduzir o desperdício de alimentos nas feiras livres de São Paulo.

## 💻 Sobre o projeto

Esta é uma versão simplificada da tela inicial do Feira Circular, criada para apresentar a estrutura visual e algumas interações da plataforma.

A interface permite selecionar três tipos de usuários:

- **Feirante:** interessado em anunciar e comercializar alimentos excedentes.
- **Consumidor:** interessado em encontrar alimentos com preços acessíveis.
- **Organização Social:** interessada em oportunidades de doação de alimentos.

Ao selecionar um perfil, o sistema apresenta uma mensagem correspondente e armazena a escolha no navegador.

## 🛠️ Tecnologias utilizadas

- HTML5 — Estrutura e organização da interface.
- CSS3 — Estilização, Flexbox, Grid e responsividade.
- JavaScript — Interatividade, manipulação do DOM e localStorage.

## 🚀 Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Selecione um dos perfis disponíveis.
4. Observe a mensagem apresentada pela interface.

Não é necessário instalar dependências ou configurar um servidor.

## 📌 Observação

Este repositório contém apenas uma **demonstração independente da interface inicial** de um projeto acadêmico maior.

As funcionalidades completas da plataforma, como autenticação, cadastro de ofertas e gerenciamento de doações, não estão implementadas nesta versão.
